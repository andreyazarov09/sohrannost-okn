Очередь обновляется раз в квартал по открытым карточкам

  1. Выгрузка

    Карточки проданных объектов загружаются через открытый API наследие.дом.рф.

  2. Группы

    Каждый объект попадает ровно в одну группу по сроку и стадии. Сводного балла нет.

  3. Список на квартал

    ДОМ.РФ отмечает объекты, и они собираются в письмо для органов охраны по регионам.

  4. Разбор

    По каждому объекту: какой ход допускает договор и кто принимает решение.
