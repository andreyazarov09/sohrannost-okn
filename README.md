# Сохранность ОКН

Прототип инструмента для ДОМ.РФ и органов охраны наследия: какие проданные объекты культурного наследия отстают от сроков и что по закону можно сделать с каждым договором.

Сайт: https://andreyazarov09.github.io/sohrannost-okn/

- Данные — выгрузка открытого API наследие.дом.рф на 30.10.2026, 1 034 проданных объекта. Демонстрационных данных нет.
- Пример расчёта — Большая казарма, Гусь-Хрустальный.
- Проектная группа 11 «ОКН в массы», программа Архитекторы.рф. Не официальный сервис ДОМ.РФ.
